First-time setup

Install and open Ollama, then run this once in your terminal:

ollama pull qwen3:4b-instruct

The model download is about 2.5 GB. After setup, generation runs on your Mac without API charges. If Ollama was set up with this project, restarting python run.py starts it automatically.

Advanced settings

Use a downloaded local text model with structured output support. Cloud models are not supported.

Your PDF text is processed on your Mac. No API key or credits needed. Scanned PDFs need OCR first. Long papers use page excerpts; figures are not read.
